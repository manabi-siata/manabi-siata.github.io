プライバシーポリシー

このポリシーは、まなびシアターが運営者自身のために使う投稿・集計ツール(Googleアカウント連携を含む)に適用されます。

1. 利用する情報

運営者本人が許可したGoogleアカウントを通じて、まなびシアターのYouTubeチャンネルに関する次の情報を利用します。

  • チャンネル名、登録者数、動画の一覧と公開日
  • 再生回数、視聴時間、視聴維持率、流入元などの集計された分析データ
  • 運営者が投稿する動画とその説明文・サムネイル

個々の視聴者を特定できる情報は取得しません。

2. 利用目的

運営者自身のチャンネルへの作品の投稿と、チャンネルごとの視聴状況を把握し、作品づくりに役立てるためだけに利用します。

3. 保存と共有

取得した情報と認証情報は、運営者のパソコン内にのみ保存します。第三者への販売・提供・共有は行いません。広告目的には利用しません。

4. Google API サービスの利用について

Google API から受け取った情報の利用と他のアプリへの移転は、Google API Services User Data Policy(限定的使用の要件を含む)に従います。

5. 連携の解除

Googleアカウントのサードパーティとの接続から、いつでも連携を解除できます。

6. お問い合わせ

このポリシーについてのお問い合わせは、まなびシアターの各YouTubeチャンネルの概要欄に記載の連絡先までお願いします。
